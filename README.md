# Titanic Survival Prediction

Machine learning project predicting Titanic passenger survival using Python and scikit-learn.

## Technologies

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure

- `notebooks/` - analysis and machine learning notebook
- `visuals/` - project visualizations
- `submission/` - final Kaggle submission
- `requirements.txt` - Python dependencies
